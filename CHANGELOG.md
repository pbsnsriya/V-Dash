## [0.1.0] - 2025-07-16

### Added

- A hotel analytics dashboard built with React, Vite and shadcn/ui, started in Lovable.
- Pages for the dashboard, revenue, forecasting, budgeting, accounting, labour analytics, night audit, on-the-books, reports, uploading daily reports and viewing or downloading reports, with a login page.
- This is the first tagged version. It describes the project as it was on 2025-07-16, before versions were tracked; the history before it is not rewritten.
